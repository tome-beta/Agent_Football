# カルチョビット仕様調査メモ

本ドキュメントは、参考タイトル「カルチョビット」（GBA版・3DS版「ポケットサッカーリーグ カルチョビット」）の選手パラメータ仕様を、攻略サイト「3DS ポケットサッカーリーグ カルチョビット 攻略wiki 組長式」（http://dqff.sakura.ne.jp/karubit/）から調査したメモ。soccer-sim の `PlayerParams` 設計の参考用。

## カルチョビットのパラメータ一覧（7種）

| パラメータ | 説明（サイト記載） |
|---|---|
| **キック** | シュートの精度／シュートのスピード／パスの正確性 |
| **メンタル** | アウェイでも力を発揮／イエローカードのもらいにくさ／スタミナ消耗後も頑張れる |
| **スタミナ** | 最大走力値。消耗するとスピード低下。時間とともに回復 |
| **フィジカル** | 当たりの強さ／疲労回復の早さ／怪我のしにくさ |
| **スピード** | 走る速さ（E系はS系の0.7倍）。スタミナを消耗するとスピード低下 |
| **テクニック** | キープ・トラップ・タックル能力 |
| **ジャンプ** | 未調査（ヘディング関連と推測） |

## soccer-sim の `PlayerParams` との対応関係（2026-08-11 再設計完了）

上記の対応関係の調査を受け、`PlayerParams` をカルチョビットの7分類に完全対応する形へ再設計した（`src/types.ts`）。

- **speed** ≒ カルチョビットの「スピード」。ただしカルチョビットは「スタミナ消耗でスピード低下」という動的要素あり。soccer-sim は現状スタミナ未実装（型のみ`stamina`フィールドを追加済み。`specification/features_1_player_ai.md` で Phase 2 予定）。
- **passAccuracy / shootPower** はカルチョビットでは「キック」1パラメータに統合されているが、soccer-sim は意図的に分離維持（劣化ではなく拡張）。
- **vision（視野）** に対応する独立パラメータはカルチョビットに無い。soccer-sim 独自拡張として維持。
- **旧 aggressiveness（積極性）は `mental`／`technique` に分解した**。カルチョビットの「テクニック」定義（キープ・トラップ・**タックル能力**）に厳密に対応するのはタックル成功率のみと判断し、`technique` に切り出した（`src/game/collision.ts`）。残り（シュート意欲・ドリブル継続時間・プレス積極性・バックサポート傾向など）はすべて「強気さ・積極性」＝カルチョビットの「メンタル」（根性・アウェイ耐性）に相当すると判断し `mental` に統一した（`src/game/player.ts`）。
- **フィジカル（当たりの強さ）**: `physical` フィールドを型のみ追加済み。`resolvePlayerPlayer`（選手同士の当たり判定）への反映はPhase 2で別途検討。
- **ジャンプ**: `jump` フィールドを型のみ追加済み。ヘディング未実装のため現状恒久的に未使用。

## 今後の参考ポイント（Phase 2 以降）

1. **スタミナ実装時**: 単純な線形減衰だけでなく、「メンタル（またはaggressiveness相当）が高いとスタミナ消耗が緩やか／消耗後も踏ん張れる」という掛け合わせを入れるとカルチョビットらしさが増す。
2. **対人接触**: 「フィジカル（当たりの強さ）」に相当するパラメータの追加を検討してもよい（`PlayerParams` 拡張候補）。
3. **キック統合 vs 分離**: soccer-sim の passAccuracy/shootPower 分離は意図的な拡張として維持してよい。

## 裏パラメータ「ポジショニング」（2026-08-09 追加調査）

上記7種の公開パラメータとは別に、画面上には表示されない**隠しパラメータ「ポジショニング」**が存在する（出典: `calciobit.com`）。

- 試合中の選手の動きを観察して推測するしかなく、画面上で数値確認はできない
- 特訓によって徐々に変化する。最初は全選手ポジションに関わらず同じ値からスタート
- **攻撃系7種・守備系5種の計12種類**:

| 守備系（5種） | 攻撃系（7種） |
|---|---|
| ゾーンマーキング | サポート |
| マンツーマン | トライアングル |
| プレッシング | マークを外す |
| シュートカット | オーバーラップ |
| インターセプト | ダイアゴナルラン |
| | スペースに走り込む |
| | ゴール前待機 |

### soccer-simへの示唆

これは`PlayerParams`（数値パラメータ）の話ではなく、**選手の行動選択の「型」そのものをパラメータ化する**という設計思想である。soccer-simの現状の非保持時ポジショニング（`computeTargetPosition`、`src/game/player.ts`）と対応づけると:

- **「ゾーンマーキング」と「マンツーマン」が独立した別パラメータ**として本家に存在する。soccer-simの守備（`decideDefensiveAction`）は現状ボール-自ゴール線へのカバーバイアス中心の**ゾーン方式のみ**で、マンマーク相当の概念が無い。`TODO.md`マイルストーンM（2026-08-09）のオフサイド調査で「守備がゾーン方式のため数的優位を活かせない可能性」を指摘しており、本家が両方式を明確に区別している事実はこの仮説の傍証になる
- 攻撃系の「トライアングル」「マークを外す」「スペースに走り込む」「サポート」は、味方の前進を助けるための位置取りという概念。soccer-simの`computeTargetPosition`（非敵保持時）には「受け手ポジション」と「バックサポート」の2択しかなく、これらに相当する多様な動きの「型」は無い
- 将来的に守備方式（ゾーン/マンツーマン）や攻撃時の動きの型を選手ごとの連続パラメータ（例: `manMarkingTendency`）として持たせる、という拡張の方向性が考えられる。ただし実装コストは大きく、`TODO.md`マイルストーンMは「大掛かりな再設計になるため未着手」と結論づけている
